# Automatic Observation

The Automatic Observation element is the text used by the `[AUTO]` variable. It is only output when the METAR is flagged `AUTO`, meaning it was generated by an automatic weather station. For METARs that are not flagged AUTO, the variable is replaced with nothing.

Set the text and voice values. The defaults are:

* **Text**: `AUTO`
* **Voice**: `Automatic Observation`

Add the `[AUTO]` variable to your Preset template where the automatic observation notice should appear, for example next to the observation time.
