# Main Window

![Main Window](/assets/images/MainScreen_Steps.png)

1. Opens the [User Settings](user-settings) window.
2. Opens the [ATIS Configuration](atis-configuration) window.
3. Window Controls: Pin Window, Toggle [Mini-Window](mini-window), Minimize and Exit. You can also double-click the title bar to toggle the Mini-Window.
4. The ATIS Stations saved to the current Profile. Connected ATIS Stations will display the ATIS letter next to the identifier. Stations you have connected are listed first, then stations that another controller is publishing (their letter is red), then the rest, each group in profile order.
5. The current ATIS letter. Left mouse-click to increment and right-mouse click to go back to the previous letter. For a station that another controller is publishing, a left-click only acknowledges a new ATIS.
6. The METAR for the selected ATIS station.
7. The current surface wind and altimeter for the ATIS station.
8. A free-form textbox for [Airport Conditions](airport-conditions), such as active runways, approaches in use, etc. Click the **AIRPORT CONDITIONS** heading to manage static messages.
9. A free-form textbox for [NOTAMs](notams). Click the **NOTAMS** heading to manage static messages.
10. Opens the [Record ATIS](voice-record-atis) dialog if the ATIS station is configured for manual recorded ATIS.
11. The [Presets](atis-configuration/presets) dropdown list.
12. The Connect or Disconnect button is used to connect or disconnect the ATIS from the network.
