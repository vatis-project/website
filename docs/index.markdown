# What is vATIS?
vATIS is a cross-platform ATIS client for [VATSIM](https://www.vatsim.net/) controllers. It builds text and voice ATIS messages from the current METAR, airport conditions and NOTAMs, and broadcasts them on the network.

# What is VATSIM?
VATSIM is the Virtual Air Traffic Simulation Network, a free online network for flight simulation. It connects pilots and volunteer air traffic controllers from around the world into one shared aviation environment.

# How do I download vATIS?
You can obtain the latest installer from the [vATIS Website](https://vatis.app).
